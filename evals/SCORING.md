# 评分标准（写死，不要每次改动）

没有写死的标准，就会反复陷入「感觉这次好一点」——而感觉不可复现，也无法
区分失败来自转写、切块、召回、重排还是提示词。

## 一、题目构成

| 类型 | 题量 | 考什么 | 失败时通常是谁的问题 |
|---|---|---|---|
| `factual` 事实 | 10 | 某个具体位置讲了什么、某个定义/步骤是什么 | 转写错字、时间戳偏移 |
| `cross` 跨段聚合 | 10 | 需要合并多处证据才能回答 | 分段边界、检索召回 |
| `visual` 视觉 | 10 | 需要看 PPT / 板书才能答对 | OCR 质量、是否给了图 |
| `global` 全局 | 10 | 统计数量、归纳全课、跨章节比较 | 摘要树质量、提示词 |

选课程要求：**2 门真实课程**，一门纯口播，一门 PPT 为主。
两者分开统计——纯口播课上「OCR 有没有用」是测不出来的。

## 二、单题打分

每题记录两个指标：

**1. 要点命中率 `keypoint_hit`**

`expect_keypoints` 里每条是一个要点。要点写成两种形式：

- 字符串 `"快速排序"`：答案里出现该串（忽略标点与空格）即算命中；
- 数组 `["O(n log n)", "O(nlogn)", "n倍log n"]`：命中**任一**写法即算命中
  （技术名词常有多种写法，不要因为写法不同判错）。

`keypoint_hit = 命中要点数 / 要点总数`

**2. 引用正确性 `citation_ok`**

如果该题写了 `expect_time`，检查回答里引用的任一时间戳是否落在
`expect_time ± tolerance_ms`（默认 90 秒）内：

- 命中：1.0
- 有引用但都在区间外：0.0（**比不引用更糟**：这是误导用户）
- 完全没引用：0.5（记为「未引用」，单独统计）

**3. 单题得分**

- 有 `expect_time`：`score = 0.7 × keypoint_hit + 0.3 × citation_ok`
- 无 `expect_time`：`score = keypoint_hit`

## 三、笔记打分

`notes_expected` 是 10 条期望要点（从课程里挑最该被写进学习文档的结论）。
在生成的 `notes.md` 上跑同样的要点命中率，记为 `notes_hit`。

额外看两个「致命缺陷」标志（不计分，但必须人眼确认）：

- **凭空编造**：笔记里出现课程完全没讲的内容 → 该次改动作废，不管分数多高；
- **丢掉整章**：某章没有输出 → 说明该章生成失败被静默吞掉。

## 四、总览指标

```
factual   = mean(score of factual)
cross     = mean(score of cross)
visual    = mean(score of visual)
global    = mean(score of global)
overall   = mean(所有题)
notes_hit = 笔记要点命中率
no_citation_rate = 未引用题数 / 有 expect_time 的题数
wrong_citation_rate = 引用错位置题数 / 有 expect_time 的题数
```

## 五、基线门槛（达到才算「能用」）

第一阶段目标（MVP 出口条件）：

| 指标 | 门槛 |
|---|---|
| `factual` | ≥ 0.80 |
| `cross` | ≥ 0.65 |
| `global` | ≥ 0.65 |
| `visual` | ≥ 0.60 |
| `overall` | ≥ 0.70 |
| `wrong_citation_rate` | ≤ 0.05 |

低于门槛时，**先看是哪个类型拖后腿**，再决定动哪一层：

- `factual` 低 → 先查转写（抽样比对音频）和时间戳对齐，不要动提示词；
- `cross` 低 → 查分段边界是否切断概念、检索是否召回；
- `visual` 低 → 先确认 OCR 是否真的抽到字，再看是否把图喂给了模型；
- `global` 低 → 查摘要树是否漏章、章节摘要是否退化成流水账。

## 六、纪律

1. **每次改动前后都跑一遍**，把两轮 `summary.json` 放在一起对比。
2. 题面一旦定稿就**不要为了让分数好看去改题**。要改题就新开一个版本的
   questions 文件，并在报告里注明。
3. 报告落到 `evals/runs/<时间戳>/`，含 `answers.jsonl`（原始回答，便于复查）
   与 `report.md`（可读结论）。
